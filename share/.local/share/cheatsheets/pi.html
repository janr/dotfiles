Pi Coding Harness Cheatsheet

Minimal terminal coding agent: files, commands, sessions, models, extensions, skills, prompts.

Hotkeys

Ctrl+C
clear editor
Ctrl+C Ctrl+C
quit
Esc
cancel / abort
Esc Esc
open session tree
Ctrl+L
model selector
Ctrl+P
cycle scoped models
Shift+Tab
cycle thinking level
Ctrl+O
collapse/expand tool output
Ctrl+T
collapse/expand thinking blocks

Slash Commands

/login
authenticate with provider
/model
switch model
/settings
thinking, theme, delivery, transport
/hotkeys
show all shortcuts
/reload
reload keys, extensions, skills, prompts, context
/copy
copy last assistant message
/export [file]
export session HTML
/quit
exit pi

Queue While Working

Enter
queue steering message after current tool calls
Alt+Enter
queue follow-up after all work finishes
Esc
abort and restore queued messages
Alt+Up
pull queued message back into editor

Start

pi
interactive session
pi "task"
interactive with initial prompt
pi -p "task"
print response and exit
cat x | pi -p
pipe stdin into a one-shot prompt
pi @file "task"
attach file(s) to prompt

Editor

@
fuzzy-search project files
Tab
path completion
Shift+Enter
new line
Ctrl+V
paste image
!cmd
run shell command and send output to model
!!cmd
run shell command only

Sessions

pi -c
continue most recent session
pi -r
browse previous sessions
pi --no-session
ephemeral mode
pi --name "x"
name session at startup
/session
show file, ID, tokens, cost
/tree
jump around session tree
/fork
new session from previous user message
/clone
duplicate current active branch
/compact
summarize older context

Models & Tools

--model sonnet:high
model plus thinking shorthand
--thinking high
set thinking level
--models "a,b"
scope Ctrl+P cycling
--list-models
list available models
--tools read,grep,find,ls
read-only-ish review mode
--no-tools
disable all tools
--exclude-tools bash
disable a specific tool

Customize

AGENTS.md
project/global instructions
.pi/settings.json
project settings
~/.pi/agent/settings.json
global settings
.pi/SYSTEM.md
replace system prompt
APPEND_SYSTEM.md
append to system prompt
prompts/*.md
slash prompt templates
skills/*/SKILL.md
on-demand capabilities
extensions/*.ts
tools, commands, UI, event hooks

Packages

pi install npm:x
install pi package
pi install git:host/u/r
install from git
pi install -l ...
project-local install
pi list
list packages
pi config
enable/disable package resources
pi update
update pi and packages
pi remove npm:x
remove package

Useful Patterns

pi -p @screenshot.png "What's in this image?"
ask about an image
pi --tools read,grep,find,ls -p "Review this repo"
review without write/bash/edit
pi --no-extensions -e ./my-ext.ts
test exactly one extension
PI_OFFLINE=1 pi
disable startup network operations
