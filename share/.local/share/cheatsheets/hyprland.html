Hyprland Cheatsheet

Launchers

Super+Return
open terminal
Super+R
open run prompt

Cheatsheets

Super+Shift+H
open Hyprland cheatsheet
Super+Shift+N
open Neovim cheatsheet
Super+Shift+P
open Pi cheatsheet

Session

Super+Ctrl+R
restart Hyprland session helpers
Super+Q
exit Hyprland
Super+F5
lower brightness
Super+F6
raise brightness

Window Focus

Super+J
focus next window
Super+K
focus previous window
Super+Tab
focus previous window
Super+Ctrl+J
focus next monitor
Super+Ctrl+K
focus previous monitor
Super+U
focus urgent or last window

Window Actions

Super+Shift+C
close active window
Super+F
toggle fullscreen
Super+M
toggle maximized fullscreen
Super+Ctrl+M
set internal fullscreen state
Super+Shift+M
set fullscreen and maximize state
Super+T
pin active window
Super+Ctrl+Shift+P
pin active window

Window Layout

Super+Space
swap active window with master
Super+Shift+L
remove a master window
Super+Ctrl+H
set master orientation left
Super+Ctrl+L
set master orientation right
Super+Shift+Space
cycle master orientation left/top
Super+Ctrl+Space
toggle floating

Move / Resize

Super+H
shrink active window width
Super+L
grow active window width
Super+O
move window to next monitor
Super+Shift+J
swap with next window
Super+Shift+K
swap with previous window
Super+Mouse1
move floating window
Super+Mouse2
resize floating window

Workspace Navigation

Super+1..9
switch laptop workspace
Super+Ctrl+1..9
switch external workspace
Super+Left
previous occupied workspace
Super+Right
next occupied workspace
Super+Up
first empty workspace
Super+Down
last empty workspace
Super+Escape
previous workspace

Move To Workspace

Super+Shift+1..9
move window to laptop workspace
Super+Ctrl+Shift+1..9
move window to external workspace
Super+Shift+Left
move window to previous workspace
Super+Shift+Right
move window to next workspace
Super+Shift+Up
move window to first empty workspace
Super+Shift+Down
move window to last empty workspace

External Workspaces

Super+Ctrl+Left
previous external workspace
Super+Ctrl+Right
next external workspace
Super+Ctrl+O
swap focused display workspace bank with main display
10..18
external monitor workspace IDs
1..9
laptop monitor workspace IDs
