Neovim Cheatsheet

LazyVim Navigation

<leader>ff
find files
<leader>sg
live grep
<leader>sk
search keymaps
<leader>e
toggle file explorer
<leader>ss
jump to symbol
<leader>sS
workspace symbols

Buffers / Windows

:bd
close buffer
:b#
switch to previous buffer
Shift-h
previous buffer
Shift-l
next buffer
Ctrl-w h/j/k/l
move between splits
Ctrl-w o
close other windows
Ctrl-w =
equalize splits

LSP / Code

gd
go to definition
gr
references
gI
go to implementation
gy
go to type definition
K
hover docs
<leader>ca
code action
<leader>cr
rename symbol
<leader>cf
format buffer

Text Objects

iw
inner word
aw
a word, including space
ip
inner paragraph
i"
inside quotes
i)
inside parentheses
i}
inside braces
it
inside tag

Diagnostics

]d
next diagnostic
[d
previous diagnostic
<leader>cd
line diagnostic
<leader>xx
diagnostics list
<leader>xX
buffer diagnostics
:copen
open quickfix
:cnext
next quickfix item

Operators

d
delete
c
change
y
yank
=
indent/format motion
gq
reflow text motion
> <
indent / unindent

Good Combos

ciw
change word
daw
delete word + space
ci"
change inside quotes
dap
delete paragraph
=ip
indent paragraph
gqap
reflow paragraph

Visual / Blocks

v
visual select
V
visual line
Ctrl-v
visual block
I
insert at block start
A
append at block end
gv
reselect last visual selection

Jumps / Marks

Ctrl-o
jump back
Ctrl-i
jump forward
ma
set mark “a”
'a
jump to mark line
`a
jump to exact mark
''
jump to previous location

Registers

"0p
paste last yanked text
"+y
yank to system clipboard
"+p
paste from system clipboard
"_d
delete without clobbering yank
:reg
show registers
Ctrl-r "
insert register in insert mode

Macros

qa
record macro into register a
q
stop recording
@a
run macro a
@@
repeat last macro
5@a
run macro five times
:reg a
inspect macro contents

Search / Replace

*
search word under cursor
:%s/foo/bar/g
replace in file
:%s/foo/bar/gc
replace with confirm
:g/pat/d
delete matching lines
:v/pat/d
delete non-matching lines
:noh
clear search highlight
